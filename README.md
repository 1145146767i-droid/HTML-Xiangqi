# HTML-Xiangqi ♟️

一个基于 HTML / CSS / JavaScript 的中国象棋网页项目，目标是做成**无需后端、打开网页即可游玩的中国象棋**。

## ✨ 当前功能

- 🀄 完整中国象棋棋盘与棋子
- ♟️ 红黑双方合法走子规则
- 🏯 九宫、河界、象眼、马腿、炮架、将军等规则
- 🚫 防止走出自将
- 👑 将军、将死、困毙检测
- 🔵 最后一步走子高亮
- 📝 中文棋谱记录
- 🔁 三次重复局面判和
- ↩️ 悔棋
- 🤖 AI 对手
- ⚙️ AI 三档难度
- 🧠 Alpha-Beta 搜索
- 🔎 迭代加深
- ⚔️ 吃子走法排序
- 🔥 静态搜索（Quiescence Search）
- 📊 子力 + 位置 + 机动性综合评估
- 🧵 Web Worker 后台计算，避免 AI 思考时卡住界面
- 🎲 仅在最佳着法分数非常接近时进行少量随机化，避免 AI 每次完全机械地走同一步

## 🤖 AI 引擎

当前 AI 已经从最初的简单随机/贪心算法升级为独立搜索引擎。

核心设计：

- 90 格一维棋盘数组
- Make / Unmake Move
- Negamax + Alpha-Beta
- Iterative Deepening
- Quiescence Search
- Capture / Check Move Ordering
- Piece-Square / Position Evaluation
- Mobility Evaluation
- Web Worker + 时间限制

### AI 难度

| 难度 | 搜索深度 | 思考时间 |
|---|---:|---:|
| 初级 | 2 层 | 约 450ms |
| 进阶 | 3 层 | 约 900ms |
| 大师 | 4 层 | 约 1500ms |

> 搜索深度和实际思考时间会受到设备性能以及局面复杂程度影响。

## 🎮 使用方法

直接打开项目中的 HTML 文件即可游玩。

- 默认玩家执红
- AI 执黑
- 可以开启/关闭 AI
- 可以切换 AI 难度
- 可以悔棋和重新开始

项目尽量保持纯前端实现，不需要安装服务器或数据库。
